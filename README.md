## Main projects

### ACCOUNTING_DESKTOP_ASSISTANT

Internal operations platform for an accounting office.

The system centralizes client data, deadlines, tax regimes, current tasks, annual closing workflows and document exchange. Its purpose is to reduce scattered manual tracking in Excel, email, Viber and folders, and to provide one controlled operational workspace for the accounting office.

### NETACONSULT_EMAIL_SYSTEM

Email ingestion and classification system for accounting-office workflows.

The system processes multiple mailboxes, classifies incoming messages by client, institution and task type, and prepares structured data for the main desktop assistant. It also supports attachment handling and downloading attachments by client and period.

### COLLEAGUE_TASK_VIEWER

Role-based task and client-information viewer for accounting-office employees.

Each employee sees only the clients, deadlines and tasks assigned to them. Tasks created in the main system are imported into the colleague’s local application and shown with a mandatory pop-up notification. The colleague can return statuses, ask questions, and send updates back to the main system, replacing scattered phone/Viber communication with structured task exchange.

## Development approach

I design tools from the accounting process outward: first the workflow, then the control points, then the automation.

The goal is not to replace professional judgment, but to remove repetitive manual work so accountants can focus on review, analysis, client advisory and quality control.
